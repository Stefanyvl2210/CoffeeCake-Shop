Preguntas frecuentes

¿Cómo puedo hacer un pedido?

Elige un cupcake desde la página principal y presiona “Comprar ahora” para completar el formulario de compra.

¿Los productos y pagos son reales?

Este sitio es un proyecto de práctica. Los productos, formularios y pagos funcionan como una demostración.

¿Puedo consultar por sabores especiales?

Sí. Puedes escribir a bakerysupplies1@gmail.com para consultar sabores, cantidades o pedidos personalizados.

¿Dónde reviso los términos?

Los términos y condiciones están disponibles desde el enlace del footer en cualquier página del sitio.

¿Qué debo revisar antes de publicar este proyecto?

Conviene revisar imágenes, textos, enlaces de pago, validación del formulario y datos reales de contacto.

¿Puedo usarlo como portafolio?

Sí. Es una buena base para mostrar práctica con HTML, CSS, responsive design y estructura de un sitio pequeño.
