# CoffeeCake's Shop

Sitio web estático de práctica para una tienda de cupcakes. Incluye una página principal con productos, una página de preguntas frecuentes, una vista de descripción, un formulario de compra de prueba y páginas de resultado de pago.

## About sugerido

CoffeeCake's Shop es un proyecto web estático creado como práctica de HTML y CSS. Simula una tienda de cupcakes con catálogo, descripción de productos, página de preguntas frecuentes, formulario de compra y páginas informativas. Es útil como ejercicio base para mejorar maquetación, responsive design y estructura de contenido en un sitio pequeño.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 4 por CDN
- JavaScript básico

## Estructura

- `index.html`: página principal, listado de productos y comentarios.
- `producto.html`: descripción de cupcakes disponibles.
- `venta.html`: formulario de compra de prueba.
- `exito.html` y `falla.html`: páginas de resultado de pago.
- `faqs.html`: preguntas frecuentes del sitio.
- `terminos.html`: términos y condiciones del sitio.
- `css/`: estilos del proyecto.
- `images/`: imágenes usadas por la tienda.
- `scripts/`: scripts del sitio.

## Cómo ejecutar

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

## Nota

Este proyecto es una práctica antigua y no debe considerarse una tienda lista para producción. Antes de publicarlo conviene revisar textos, enlaces de pago, validación de formularios, accesibilidad y derechos de uso de imágenes.
